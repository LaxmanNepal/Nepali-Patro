# Nepali-Patro Gold → WhatsApp Channel Bot

Open-source WhatsApp Channel automation using Baileys. The bot reads the dated JSON generated by Nepali-Patro and publishes today's gold/silver rate once per AD date.

## How it works

1. Nepali-Patro GitHub Actions updates `feeds/gold_silver.json` from NEGOSIDA.
2. The daily snapshot workflow creates `feeds/gold_daily/YYYY-MM-DD.json`.
3. This bot polls that public directory every 15 minutes.
4. It posts the current day's rate to the configured WhatsApp Channel.
5. `data/posted.json` prevents duplicate posts.

## Configuration

Copy `.env.example` to `.env` and set:

- `WHATSAPP_PHONE`: the WhatsApp account's phone number, digits only, including country code.
- `WHATSAPP_CHANNEL_JID`: the Channel JID ending in `@newsletter`.

The first run prints a pairing code when `WHATSAPP_PHONE` is set. Link the WhatsApp account from **WhatsApp → Linked devices → Link a device → Link with phone number instead**. Keep the `auth/` directory persistent after pairing.

## Run locally

```bash
npm install
node bot.js
```

## Docker

```bash
docker build -t nepali-patro-gold-whatsapp .
docker run -d --name gold-whatsapp \
  --restart unless-stopped \
  --env-file .env \
  -v $(pwd)/auth:/app/auth \
  -v $(pwd)/data:/app/data \
  nepali-patro-gold-whatsapp
```

## Important

Baileys is an unofficial WhatsApp Web automation library. It is not the official WhatsApp Business API. Keep posting limited to legitimate channel content and do not use the bot for spam.
